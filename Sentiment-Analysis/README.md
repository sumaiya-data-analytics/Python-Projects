# Sentiment Analysis Using Python

# Project Overview
This project focuses on performing sentiment analysis on textual data using Python. It analyzes sentences and identifies whether the expressed sentiment is Positive, Negative, or Neutral.

The project also uses WordCloud visualization to highlight frequently occurring words in negative sentences.

# Tools & Technologies
- Python
- Jupyter Notebook
- Pandas
- TextBlob
- Matplotlib
- Seaborn
- WordCloud

# Project Objectives
- Analyze textual data using Python.
- Identify positive, negative, and neutral sentiments.
- Understand the distribution of sentiments.
- Extract and analyze negative sentences.
- Visualize frequently occurring words in negative sentences using WordCloud.

# Work Performed
1. Imported the dataset using Pandas.
2. Processed and analyzed textual sentences.
3. Used TextBlob to calculate sentiment polarity.
4. Classified sentences into Positive, Negative, and Neutral categories.
5. Filtered and separated negative sentences.
6. Combined negative sentences for further analysis.
7. Created a WordCloud to visualize frequently occurring words in negative sentences.

# Key Features
- Text sentiment classification.
- Positive, Negative, and Neutral sentiment identification.
- Negative sentence extraction.
- WordCloud visualization.
- Data processing and analysis.

# Key Learnings
- Working with textual datasets using Pandas.
- Understanding sentiment analysis.
- Using TextBlob for sentiment classification.
- Text preprocessing and filtering.
- Creating data visualizations using Python.

# Project Files
- `Sentiment_Analysis.ipynb` – Jupyter Notebook containing the Python code and analysis.
- `sentiment_analysis_dataset.csv` – Dataset used for sentiment analysis.

# Conclusion
This project provided practical experience in text analysis, sentiment classification, and data visualization using Python. It helped develop an understanding of how natural language processing techniques can be used to extract meaningful insights from textual data.
