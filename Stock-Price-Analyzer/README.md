# Stock Price Analyzer Using Python

# Project Overview
This project focuses on analyzing stock market data using Python. It retrieves stock information and historical stock prices using the Yahoo Finance library (yfinance).

The project calculates daily price changes and moving averages to understand stock price trends over a selected period. It also generates visualizations to compare daily stock prices with moving averages.

# Tools & Technologies
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- yfinance

# Project Objectives
- Retrieve stock market information using Python.
- Display company names and current stock prices.
- Calculate daily price changes and percentage changes.
- Analyze historical stock prices for a selected date range.
- Calculate 7-day and 30-day moving averages.
- Visualize stock price trends using graphs.

# Work Performed
1. Imported the required Python libraries.
2. Used yfinance to retrieve stock market information.
3. Accepted stock symbols from users.
4. Retrieved company names, current prices, previous closing prices, and currency.
5. Calculated price differences and percentage changes.
6. Downloaded historical stock data based on user-selected start and end dates.
7. Calculated 7-day and 30-day moving averages using Pandas.
8. Created line graphs using Matplotlib to compare daily stock prices with moving averages.
9. Added error handling for invalid stock symbols and network errors.

# Key Features
- User-input-based stock symbol selection.
- Live stock information retrieval through Yahoo Finance.
- Daily price change and percentage change calculation.
- Historical stock price analysis.
- 7-day and 30-day moving average calculations.
- Graphical representation of stock price trends.
